# BacktoBase

The BacktoBase community website, built with Next.js, React, TypeScript, and
Tailwind CSS.

## Development

```bash
pnpm install
pnpm dev
```

## Checks

```bash
pnpm typecheck
pnpm lint
pnpm test
```

See [event content and join application setup](docs/events-content.md) for
editing the event catalogue and configuring online application delivery.
